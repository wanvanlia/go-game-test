# 接球小游戏（Catch the Balls）

使用 Go 语言和 [Ebiten](https://ebitengine.org/) 游戏引擎开发的休闲接球小游戏。移动鼠标控制底部的小箩筐，接住从天而降的彩色小球吧！

## 玩法说明

- 彩色小球会从屏幕顶部随机位置不断掉落，发射间隔为 **1~3 秒**
- 小箩筐位于屏幕底部，**跟随鼠标水平移动**
- 用箩筐接住小球得 **1 分**
- 小球落出屏幕底部即为漏接，漏接 **10 个**游戏结束
- 游戏结束后按 **空格键** 重新开始

## 操作方式

| 操作 | 按键/动作 |
| --- | --- |
| 移动箩筐 | 移动鼠标 |
| 重新开始 | 空格键 |
| 退出游戏 | 关闭窗口 |

## 环境要求

- Go 1.24+
- 已启用 Go Modules

## 运行方式

```bash
# 拉取依赖（如网络访问 proxy.golang.org 受限，可先切换国内镜像）
go env -w GOPROXY=https://goproxy.cn,direct
go mod tidy

# 直接运行
go run .
```

也可以先编译再运行：

```bash
go build -o catch.exe .
./catch.exe
```

## 实现简介

- `Ball`：描述小球的位置、下落速度和颜色
- `Game`：维护小球列表、箩筐位置、得分、漏接数和游戏状态
- 游戏以固定帧率（60 FPS）运行：
  - `Update()` 处理鼠标跟随、定时发射小球、移动和碰撞检测
  - `Draw()` 绘制背景、小球、箩筐与分数信息
- 碰撞判定：当小球进入箩筐高度区间且其 x 坐标落在箩筐宽度内，即视为接住

## 可调参数

在 [main.go](main.go) 顶部的常量和随机区间可以调整游戏难度：

- `randomSpawnInterval()`：小球发射间隔（默认 1~3 秒）
- `speed: 2 + rand.Float64()*2`：小球下落速度（默认 2~4 像素/帧）
- 漏接上限 `10`：达到后游戏结束
- `screenWidth` / `screenHeight`：窗口大小
